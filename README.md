# PSX Controller

UNO R4 双 PS2 摇杆和 A/B/X/Y 四个按键输入测试。当前通过串口输出，尚未实现电脑 USB 游戏手柄映射。

## 程序文件

所有代码位于 `Test/sketch_nov2a/`：

- `sketch_nov2a.ino`：主程序、双摇杆采集、中心校准、灵敏度和串口输出。
- `Buttons.h`：A/B/X/Y 和摇杆按压键 L3/R3 共六个按键的接口。
- `Buttons.cpp`：六个按键的引脚、电平设置和独立消抖。

这些文件共同编译成一个固件，只上传一次。不要单独编译或上传 `Buttons.cpp`，也不要手动 `#include "Buttons.cpp"`。

## 接线

仓库中的 `ABX00087-full-pinout.pdf` 是 UNO R4 WiFi 开发板引脚图，不是按键模块电路图。

| 输入 | 开发板引脚 |
| --- | --- |
| 摇杆 1 X / Y / SW（L3） | A2 / A1 / D2 |
| 摇杆 2 X / Y / SW（R3） | A3 / A0 / D3 |
| 按键 A | D4 |
| 按键 B | D5 |
| 按键 X | D6 |
| 按键 Y | D7 |
| 预留 OLED SDA / SCL | A4 / A5 |

两个摇杆 VCC 接 5V，GND 接开发板 GND。四个独立按键各有一端接指定 D 引脚，另一端接 GND，使用内部上拉，按下为 LOW。四脚轻触开关应连接按下时才导通的两组触点。

若使用按键模块：S 接指定引脚，GND 共地，VCC 按模块要求供电。默认按下输出 LOW；高电平有效的模块需将 `Buttons.cpp` 的 `ACTIVE_LOW` 改为 `false`，且模块必须提供稳定的松开电平。

两个摇杆模块的 SW 分别接 D2、D3，模块 GND 与开发板共地。SW 使用内部上拉，松开为 HIGH，按下接地为 LOW，程序转换为松开 0、按下 1。L3/R3 始终为低电平有效，不受 A/B/X/Y 的 `ACTIVE_LOW` 设置影响。

为后续四针 I²C OLED 预留 A4（SDA）、A5（SCL）。UNO R4 上单独标出的 SDA/SCL 与 A4/A5 共用信号，不能同时用于摇杆输入。OLED 的 GND 接共地，VCC 按具体模块额定电压供电；当前代码尚未包含 OLED 显示功能。

从旧接线升级时，需要移动三根信号线：摇杆 1 SW 从 A0 移到 D2；摇杆 2 Y 从 A4 移到 A0；摇杆 2 SW 从 A5 移到 D3。调整后再上传新版程序。

六个按键每 5ms 读取一次，按下或松开连续稳定 20ms 后更新，允许六键同时按下，不阻塞摇杆采集。代码中可用 `Buttons::isPressed(Buttons::L3)`、`Buttons::isPressed(Buttons::R3)` 查询两个 SW 的消抖状态。

## Arduino IDE 编译与烧录

1. 打开 `Test/sketch_nov2a/sketch_nov2a.ino`。确认同目录有 `Buttons.h` 和 `Buttons.cpp`，IDE 中会显示对应标签页。
2. 在开发板管理器中安装 **Arduino UNO R4 Boards**（已安装则跳过）。无需另外安装库。
3. 用 USB 数据线连接开发板。在 **工具 -> 开发板 -> Arduino UNO R4 Boards** 选择 **Arduino UNO R4 WiFi**；如果实际使用 Minima，改选 Minima。
4. 在 **工具 -> 端口** 中选择开发板对应的 COM 口。
5. 点击左上角 **验证（勾号）** 编译整个项目。
6. 关闭 VOFA、串口监视器和其他占用该 COM 口的软件，然后点击 **上传（右箭头）**。上电、上传后复位时松开两个摇杆，以便校准中心。
7. 上传完成后打开 VOFA，选择同一 COM 口、**115200** 和 **FireWater** 协议，再连接。串口监视器与 VOFA 不要同时占用同一个端口。

## VOFA 通道

每 50ms 发送一个带换行的 FireWater 数据帧。原有 0～9 通道顺序不变，新按键追加到末尾。

| 通道 | 内容 | 范围 |
| --- | --- | --- |
| 0 / 1 | 摇杆 1 处理后的 X / Y | -1000～1000，回中为 0 |
| 2 / 3 | 摇杆 2 处理后的 X / Y | -1000～1000，回中为 0 |
| 4 / 5 | 摇杆 1 SW（L3）/ 摇杆 2 SW（R3） | 松开 0，按下 1 |
| 6 / 7 | 摇杆 1 原始 X / Y | 0～1023 |
| 8 / 9 | 摇杆 2 原始 X / Y | 0～1023 |
| 10 | 按键 A（D4） | 松开 0，按下 1 |
| 11 | 按键 B（D5） | 松开 0，按下 1 |
| 12 | 按键 X（D6） | 松开 0，按下 1 |
| 13 | 按键 Y（D7） | 松开 0，按下 1 |

将 10～13 通道绑定到单独的波形图，点击 Auto 调整纵轴，更容易观察 0/1 按键状态。按住时保持 1，松开后恢复 0。

如需人工可读文字，将 `.ino` 中的 `VOFA_OUTPUT` 改为 `false`，重新编译上传，再用串口监视器查看；此模式不用于 FireWater 绘图。

## 上板检查

- 分别按 A/B/X/Y，确认只有对应的 10/11/12/13 通道变为 1。
- 分别按下两个摇杆，确认通道 4（L3）/ 5（R3）变为 1，松开后回到 0。
- 同时按住 L3/R3 和 A/B/X/Y，六个按键通道应同时为 1；推动摇杆时四轴应继续响应。
- 四键同时按住，应全部为 1；逐个松开，应分别回到 0。
- 按键时同时推动两个摇杆，检查摇杆通道仍正常响应。
- 松手时摇杆处理值为 0，所有按键状态为 0。
