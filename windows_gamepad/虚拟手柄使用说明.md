# 虚拟 Xbox 360 手柄使用说明

本项目将 Arduino 的两个摇杆和 A/B/X/Y 四个实体按键转换成 Windows 可识别的虚拟 Xbox 360 手柄。L3/R3、十字键、肩键和扳机暂未映射。

## 一、安装和启动

1. 从 GitHub [Releases](https://github.com/kuranshi/PSX-Controller/releases) 下载 x64 安装程序并运行。安装程序需要管理员权限。
2. 安装程序会在未发现 ViGEmBus 驱动时打开其官方安装器。按屏幕提示完成安装；若提示重启，请重启电脑后继续。
3. 用 USB 连接 Arduino，确认设备管理器出现对应串口。COM 号会因电脑或 USB 插口而变化。
4. 从开始菜单打开“PSX Controller”。窗口会尝试自动选择 Arduino；检查 COM 号，必要时点“刷新”，然后点“连接手柄”。
5. 关闭 VOFA、Arduino 串口监视器及其他串口程序。一个 COM 口同一时间只能由一个程序打开。

如从源码运行，先安装 ViGEmBus 驱动，在 PowerShell 进入 `windows_gamepad` 目录后执行：

```powershell
python -m venv .venv-gamepad
$env:VGAMEPAD_SKIP_VIGEMBUS_INSTALL = 'true'
.\.venv-gamepad\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-gamepad\Scripts\python.exe .\controller_app.py --port COM3
```

可以不传 `--port COM3`，随后在窗口里选择串口。关闭窗口或点击“断开”会释放手柄并回中摇杆、松开按键。

## 二、确认 Windows 已识别

1. 先启动程序并连接 Arduino，保持窗口运行。
2. 按 `Win+R`，输入 `joy.cpl` 并回车。
3. 选中 Xbox 360 控制器，打开“属性 → 测试”。推动两个摇杆，观察左右摇杆指示；按下 A/B/X/Y，观察对应按钮是否亮起。松开后应回中或熄灭。

设备管理器中 `Nefarius Virtual Gamepad Emulation Bus` 表示驱动已加载；Xbox 控制器通常只在桌面程序运行时显示。也可用[网页手柄测试器](https://hardwaretester.com/gamepad)检查输入。

## 三、通道和按键映射

| Arduino 串口数据 | 虚拟 Xbox 360 手柄 |
| --- | --- |
| 通道 0/1：摇杆 1 X/Y | 左摇杆 X/Y |
| 通道 2/3：摇杆 2 X/Y | 右摇杆 X/Y |
| 通道 10：A | Xbox A |
| 通道 11：B | Xbox B |
| 通道 12：X | Xbox X |
| 通道 13：Y | Xbox Y |

串口为 115200 波特率。固件输出 `joystick:` 开头的 14 通道 FireWater 行，约每 50 ms 一帧；摇杆处理值范围 `-1000～1000`，按键按下为 `1`、松开为 `0`。程序收到串口数据超时后会让摇杆回中并释放按键。

如果 Y 方向反了，源码运行时可按需加入 `--invert-left-y` 或 `--invert-right-y`，例如：

```powershell
.\.venv-gamepad\Scripts\python.exe .\controller_app.py --port COM3 --invert-left-y
```

## 四、常见问题

### COM 口提示拒绝访问

关闭 VOFA、Arduino 串口监视器及其他可能连接 Arduino 的程序，再刷新端口并重试。不要同时开多个桥接程序。

### Windows 找不到 Xbox 手柄

- 确认桌面程序正在运行且已连接，串口状态没有报错。
- 确认 ViGEmBus 已安装。设备管理器中应看到 `Nefarius Virtual Gamepad Emulation Bus`。
- 如果刚安装驱动，按安装器提示重启电脑。

### 手柄存在但轴不动

- 确认窗口选的是 Arduino 当前 COM 口，且没有其他程序占用它。
- 检查 Arduino 正在输出 115200 波特率的 `joystick:` 数据。
- 检查 A/B/X/Y 固件通道 10～13 是否按下为 1。
- 上电或按 RESET 校准时，先松开两个摇杆。

### ViGEmBus 驱动说明

本安装程序提供 ViGEmBus 1.22.0 官方签名安装器。该驱动项目已经停止维护；许可和依赖来源见安装目录 `licenses` 文件夹中的第三方声明。安装驱动需要管理员权限，某些系统会要求重启。
